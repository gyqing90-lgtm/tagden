物种标注工坊 · macOS 版 使用说明
========================================

一、选哪个包
  物种标注工坊-mac-arm64.zip                            → Apple Silicon（M1/M2/M3/M4）
  物种标注工坊-mac-x64.zip                            → Intel 芯片的 Mac
  不确定就点左上角苹果菜单 →「关于本机」，看「芯片」一行。

二、安装与启动
  1. 解压 zip，得到一个「物种标注工坊-mac-xxx」文件夹。
  2. 把整个文件夹放到固定位置（例如「应用程序」或用户目录），
     里面的 node、app、start.command 三层必须在一起，不要只拷单个文件。
  3. 双击 start.command，会开一个终端窗口，随后自动打开浏览器
     http://127.0.0.1:7801 。浏览器没自动弹就自己输入这个地址。

  首次打开若被系统拦下（提示「无法打开 / 未验证的开发者」）：
    在「系统设置 → 隐私与安全性」里点「仍要打开」；
    或在该文件夹上右键「打开」一次。
    也可以打开终端，执行（把路径换成你实际放的位置）：
      xattr -dr com.apple.quarantine "/Applications/物种标注工坊-mac-arm64"
  这是本地打包的免费工具、没有苹果开发者签名，属正常提示，只需放行一次。

三、停止与端口
  在终端窗口按 Ctrl+C，或直接关闭该窗口，服务即停止。
  默认端口 7801；被别的程序占用时，可在终端里这样启动：
    cd 到该文件夹 && ./start.command --port 8080
  然后浏览器访问 http://127.0.0.1:8080 （换成你指定的端口）。

四、配置与数据
  配置和登录缓存放在程序文件夹同级的 data/（被聚合台占用时为 data-tagden/），
  跟着程序走：整个文件夹拷走，账号和偏好一起带走。
  图片始终留在本机，只有点「识别」时才会把当前这张图发给所选鉴定站点。

五、自动更新
  界面里的「检查更新」会读取线上 latest-mac.json，只替换 app/main.js
  （约 3 MB，几秒完成），包内 node 运行时不动，所以签名始终有效。
  Apple Silicon 与 Intel 共用同一份更新包。
  更新完成后程序会自动重启一次，期间页面短暂断开属正常。

六、常见问题
  · 页面打不开：确认终端窗口还在（服务在前台运行）；确认端口没错。
  · 左侧文件夹树点不开：请用 v0.6.21 或更新版本，该版已修复 macOS 路径。
  · 首次使用某些站点要登录：界面里填一次账号即可，凭据加密存在本地 data/。
  · 照片评分的「本地引擎」是 Windows exe 独有的内置运行库功能；
    macOS 版请用云端评分或自备模型。
